# Identidad gráfica · Test de las Líneas

- `inspector.svg`: retrato vectorial principal, con fondo transparente. Úsalo en tamaños medianos o grandes.
- `inspector-mark.svg`: recorte compacto para la marca horizontal de la interfaz.
- `favicon.svg`: dibujo simplificado para tamaños pequeños, con fondo marfil.
- `inspector-mono.svg`: versión en negro y blanco para impresión a una tinta.
- `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`: íconos de dispositivo.
- `social-card.png`: imagen para compartir enlaces.

Colores de la marca: carbón `#242728`, ocre `#D3B16B`, rojo `#C94B2A` y marfil `#F6F1E6`.

Los PNG y la versión monocroma se regeneran con `node scripts/generate-brand-assets.cjs` desde la raíz del proyecto.
